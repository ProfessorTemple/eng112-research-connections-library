Begin with a question

A word, a memory, or a disagreement is enough. Try a concept search, then complicate what you find.

Use AND to narrow, OR to broaden, and NOT to exclude. Example: animals AND communication NOT film. An ordinary search uses broad matching. Results are leads to investigate, not pre-approved evidence. Verify each original publication before citing it.

About this classroom pilot and student privacy

Pedagogy: begin from lived attention, question your first interpretation, consider different kinds of evidence, and explain how your thinking changed. Anna Reading’s Rewilding Memory is a foundational connecting work, not a source every other work must agree with.

Library access: print-reserve information comes from the PCC Library list dated November 17, 2026. E-books may require a PCC login. Availability and links need a final library check.

Editorial caution: catalog records remain at different verification stages. Curated entries have fuller teaching notes, while other records remain leads to investigate. A DOI or inclusion does not guarantee that research claims are correct. No student essays, names, or private writing appear in the source database.

Accessibility: controls have text labels, keyboard focus styles, non-color-based statuses, live status messages, and responsive layout. A complete WCAG 2.1 AA audit, including VoiceOver and keyboard user testing, is still needed before describing the site as compliant.

This independent preview does not modify the live Research as Encounter website. No analytics or external scripts are embedded. Opening a source link leaves the preview for an external publisher or PCC Library page.

Updating the library: the source database lives in a separate data/sources.json file. New sources can be reviewed and added without rewriting the application. Source IDs remain stable so saved trails can survive routine additions.

Accessibility status: this version has been checked for programmatic labels, responsive reflow, keyboard navigation, and browser behavior. That is not a certification of WCAG compliance. Safari/VoiceOver, Safari keyboard settings, and real students using assistive technology must still be tested before formal classroom adoption.

Research limitations: not every source has completed bibliographic or access review. The 38 curated entries have teaching notes; uncurated records remain leads. If a link is restricted, try PCC Library access or ask the librarian. Do not post student writing or student data to the public source catalog.
